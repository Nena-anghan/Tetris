# Tetris

A classic Tetris game written in C++.

## Features
- Real-time tetromino movement and rotation
- Line clearing and score tracking
- High score persistence
- Level progression with increasing speed

## Controls
- **Left/Right Arrow:** Move the current piece
- **Up Arrow:** Rotate the piece
- **Down Arrow:** Soft drop
- **Space:** Hard drop
- **P:** Pause/Resume the game

## Building

Compile the source files with a C++ compiler:

```bash
g++ *.cc -o tetris
```

## Running

```bash
./tetris
```
